# Third-party integrations

This repository contains configuration examples and usage guidance only. It does not redistribute the named third-party projects.

Review upstream licenses, security posture, and version compatibility before installation. See `references/upstream-sources.md`.

Notable categories:

- MIT / Apache/open-source CLI and MCP projects may have their own dependency licenses.
- Remote services such as DeepWiki and hosted Mem0 have separate service terms/privacy policies.
- JetBrains MCP is managed by the installed JetBrains IDE.
- Letta is treated as an alternative/persistent agent architecture, not as a dependency of this plugin.
